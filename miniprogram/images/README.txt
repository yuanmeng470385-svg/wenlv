TabBar 图标需要放置以下6个PNG图片文件（建议 81x81 像素）:

1. tab-home.png         - 首页图标（未选中）
2. tab-home-active.png  - 首页图标（选中时，颜色 #C48B5C）
3. tab-order.png        - 订单图标（未选中）
4. tab-order-active.png - 订单图标（选中时，颜色 #C48B5C）
5. tab-mine.png         - 我的图标（未选中）
6. tab-mine-active.png  - 我的图标（选中时，颜色 #C48B5C）

可从以下途径获取:
- 微信开发者工具未提供默认图标时需要自行准备
- 推荐使用 iconfont 下载或 UI 设计工具制作
- 临时可用纯色矩形替代，确保编译通过
