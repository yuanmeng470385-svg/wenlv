01

设计理念

Concept

现版 UI 是通用的暖棕卡片风，与「汉服 / 文旅 / 摄影」的品类气质脱节。新设计以宣纸与墨色为底、朱砂为点睛之色、宋体为骨相，把「逛店」变成「翻画册」——让用户在预约之前，先感受到东方美学的仪式感。图标全部重绘为 1.5px 圆角线条 SVG，替代现有的 emoji 与杂色 PNG。

纸墨留白

宣纸色底 + 墨色文字 + 发丝级描边，去掉厚重阴影与彩色大按钮墙。信息靠留白与字重分层，而非色块堆砌。

朱砂点睛

全界面只有三种强调色：朱砂（价格 / 主操作 / 警示）、黛青（进行中 / 成功）、泥金（评分 / 轻奢点缀）。克制即高级。

宋体为骨

标题与数字用明朝体（Noto Serif SC），正文用黑体，印章与品牌字用书法体。竖排小字作为画册式装饰贯穿各页面。

03

字体系统

Typography

三级字体制：明朝体承担标题、价格、统计数字（画册感）；黑体承担正文与控件（可读性）；书法体只用于印章与品牌字（仪式感）。小程序落地时标题可用系统宋体（iOS Songti / Android 内嵌思源宋）。

04

图标系统

Icons

37 枚全部重绘：24×24 网格、1.5px 线宽、圆角收尾、无填充，风格统一为「细线白描」。品类别三枚定制：相机（摄影）、口红（妆造）、交领襦裙（汉服店）。落地方式：导出为单色 PNG（tabBar 用）或以 SVG 内联 / iconfont 用于页面内，颜色由 CSS currentColor 控制，一套图形适配所有状态。

09

落地规范

Tokens

以下变量可直接替换 miniprogram/styles/variables.wxss；图标导出 24px SVG / 81×81 PNG（tabBar）；页面骨架按本预览 1:1 还原为 WXML 即可。

page {
  /* 纸墨色板 */
  --paper:      #F6F1E7;  /* 页面底（原 --bg-page） */
  --paper-2:    #FBF8F0;  /* 吸顶区 / 底栏 */
  --card:       #FFFDF7;  /* 卡片 */
  --ink:        #29241D;  /* 主文字 / 主按钮 */
  --ink-2:      #6E675C;  /* 次文字 */
  --ink-3:      #A79E8F;  /* 弱提示 */
  --line:       rgba(41,36,29,.14);
  --line-2:     rgba(41,36,29,.07);

  /* 强调色（全局仅这三种） */
  --red:        #BE3F2C;  /* 朱砂：价格 / 主操作 / 警示 */
  --red-deep:   #9E3020;
  --celadon:    #43615C;  /* 黛青：进行中 / 成功 */
  --gold:       #B08D57;  /* 泥金：评分 / 轻奢点缀 */
  --star:       #C99345;

  /* 字体 */
  --f-serif: "Noto Serif SC","Songti SC","SimSun",serif;
  --f-sans:  "Noto Sans SC","PingFang SC","Microsoft YaHei",sans-serif;

  /* 圆角（克制） */
  --r-sm: 10rpx; --r-md: 24rpx; --r-lg: 32rpx; --r-pill: 999rpx;
}

图标落地

页面内：SVG 转 base64 内联或 iconfont，颜色跟随 currentColor；tabBar：导出 81×81 PNG，未选中 #A79E8F、选中 #29241D + 朱砂指示点（指示点需自定义 tabBar 或在图标内绘制）。

字体落地

小程序内嵌思源宋体子集（仅标题字 ~200 字）控制包体积；iOS 可退化 Songti SC、Android 退化系统默认衬线。正文保持系统黑体，零成本。

间距与圆角

页面边距 32rpx；卡片间距 20-24rpx；卡片圆角 32rpx、图片 24rpx、按钮全圆角。阴影仅一种：0 28rpx 68rpx -36rpx rgba(41,36,29,.22)。

兼容提醒

沿用既有约束：flex 不用 gap（用 margin 替代）、双列用 width:50% + 内 padding、颜色一律走 CSS 变量。
